# sorokit-ui

`sorokit-ui` is the React UI kit for building interfaces on top of `sorokit-core`.

Use it when you want accessible components, provider patterns, and interaction flows that match the core SDK.

## What Belongs Here

- React components
- Context providers
- Hooks for UI state
- Layout primitives
- Examples that connect components to `sorokit-core`
