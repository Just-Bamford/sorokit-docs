# Components

Use this page as the starting inventory for `sorokit-ui` components.

## Component Documentation Pattern

Each component page should include:

- Purpose
- Import path
- Basic example
- Props
- Accessibility notes
- Composition examples

## Planned Categories

| Category | Description |
| --- | --- |
| Providers | App-level context and configuration |
| Controls | Buttons, inputs, selectors, toggles |
| Feedback | Status, errors, loading states |
| Workflow | Higher-level sorokit interaction components |
