# WalletButton

`WalletButton` will document the primary wallet connection control for `@sorokit/ui`.

## Purpose

Use this component when an interface needs to connect, disconnect, or display the current wallet session through a compact action surface.

## Import

```tsx
import { WalletButton } from '@sorokit/ui'
```
