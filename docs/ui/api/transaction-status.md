# TransactionStatus

`TransactionStatus` will document the transaction feedback component for `@sorokit/ui`.

## Purpose

Use this component when an interface needs to show transaction progress, success, failure, or pending network confirmation.

## Import

```tsx
import { TransactionStatus } from '@sorokit/ui'
```
