# NetworkSwitcher

`NetworkSwitcher` will document the network selection component for `@sorokit/ui`.

## Purpose

Use this component when an interface needs to switch between supported networks or display the active network context.

## Import

```tsx
import { NetworkSwitcher } from '@sorokit/ui'
```
