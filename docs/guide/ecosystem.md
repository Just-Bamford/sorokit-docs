# Ecosystem

sorokit is split into a core SDK and a UI kit so teams can choose the right level of abstraction.

## Shared Foundation

`sorokit-core` owns the framework-independent behavior. It should remain portable, testable, and usable outside React.

## React Layer

`sorokit-ui` owns the React components and provider patterns. It should make common product workflows fast to assemble while leaving advanced teams room to customize.

## Documentation Goals

This site should help users:

- Understand which package they need.
- Install and configure the packages with confidence.
- Move from concepts to working examples quickly.
- Find API and configuration references without hunting through source code.
