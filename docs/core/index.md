# sorokit-core

`sorokit-core` is the framework-agnostic TypeScript SDK for the sorokit ecosystem.

Use it when you need the underlying primitives without committing to a UI framework. It is the right layer for shared business logic, package integrations, tests, and applications that do not use React.

## What Belongs Here

- TypeScript-first APIs
- Framework-independent state and behavior
- Configuration primitives
- Runtime adapters
- Utilities that can be consumed by `sorokit-ui`
